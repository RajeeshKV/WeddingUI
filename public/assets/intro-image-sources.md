# Wedding intro image and motion audit

This audit covers all 15 intro themes. Backgrounds are local WebP files at `public/assets/<theme>-bg.webp`; the running site does not hotlink images. Unsplash pages below identify the photos as free to use under the Unsplash License. The license permits commercial and non-commercial use; attribution is appreciated but not required: [Unsplash License](https://unsplash.com/license).

Image choices prioritize composition, readable center space, and mobile-safe focal points. The restored Eternal Bloom image is an earlier project asset from Git history. Its original creator and license were not recorded, so its provenance remains unverified; it is retained because the user specifically preferred that previous frame composition. Other changed images were downloaded from the source photo pages and converted to local WebP crops at 2000 × 1125, `q=76`.

## Implementation and test notes

- Shared `IntroDispatcher`, `InvitationExperience`, `IntroShell`, invitation letter, data, theme selection, and open/CTA behavior remain intact.
- Per-theme choreography lives in `src/components/intro/ThemeMotion.jsx`; reduced motion skips decorative motion, while the invitation content and background remain visible without entrance movement.
- All 15 assets are local; photo dimensions and WebP signatures are checked as part of this audit. Production `npm run build` succeeds.
- The local preview was started on port 5175 for desktop/mobile checks. Browser automation denied origin access and reported the approval was declined. Per that gate, no alternate browser/CDP path was attempted. Consequently real viewport rendering, console inspection, and reduced-motion playback still need browser validation; the table marks this status honestly for each theme.
- The restored Eternal Bloom asset’s original license/creator is the one unresolved image-provenance limitation.
