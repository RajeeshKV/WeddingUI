## Implementation notes

- All themes continue to use the existing `IntroDispatcher`, `InvitationExperience`, `IntroShell`, invitation letter, and `onOpen` flow. No RSVP, theme selection, or invitation data behavior was changed.
- Animation primitives are grouped in `src/components/intro/ThemeMotion.jsx`, with separate per-theme scenes and a shared `prefers-reduced-motion` gate. Petal distributions are memoized so a state update does not reshuffle them.
- The production build succeeds and all 15 local asset files have valid WebP signatures. Desktop/mobile animation playback was not manually browser-tested in this pass; responsive layout and reduced motion are covered in CSS and the `useReducedMotion` gate.
